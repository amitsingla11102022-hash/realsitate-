# Skyline Homes — Real Estate Landing Page

Responsive static landing page based on the approved Skyline Homes design.

## Files
- `index.html` — page structure and dummy property/contact data
- `styles.css` — responsive styling
- `script.js` — navigation, property search feedback, property modal, lead form interaction

## Run locally
Open `index.html` in a browser, or use any static server.

Example:
```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
